# 🍺 g1mn Homebrew Tap

Official Homebrew Formulae for tools developed by [@g1mn](https://github.com/g1mn).

## How to Install Formulae

### agyswap
Fast Multi-Account Switcher & Session Manager for Google Antigravity (`agy`) CLI on macOS.

```bash
brew install g1mn/tap/agyswap
# or
brew tap g1mn/tap
brew install agyswap
```
